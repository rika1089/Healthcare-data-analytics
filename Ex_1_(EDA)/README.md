# Exercise 1 - Exploratory Data Analysis (EDA)

## Overview
This exercise performs exploratory data analysis on the Pima Indians Diabetes dataset from the National Institute of Diabetes and Digestive and Kidney Diseases (NIDDK). The notebooks walk through loading the data, inspecting feature distributions, and exploring relationships between diagnostic measurements and the diabetes outcome.

## What the notebooks cover
- Load the diabetes dataset from a local CSV and from a URL.
- Descriptive statistics and distribution visualizations.
- Correlation heatmap and scatter plot matrix.
- Demographic and health-indicator analysis (age, pregnancies, glucose, BMI).
- A small synthetic dataset example for EDA practice.

## Contents
- `Ex_1(EDA_on_Diabetes).ipynb` — EDA on the local `diabetes.csv` with feature descriptions.
- `Ex_1(EDA_using URL).ipynb` — EDA and visualization workflow using a dataset loaded from a URL.
- `Generating_Random_dataset.ipynb` — Generates a small random dataset and converts it to a DataFrame.
- `diabetes.csv` — Diabetes dataset used in the notebooks.

## How to run
Open the notebooks in Jupyter Notebook or Google Colab and ensure the standard data stack is installed (`pandas`, `numpy`, `matplotlib`, `seaborn`).
