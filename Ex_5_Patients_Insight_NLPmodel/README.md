# Exercise 5 - Patient Insight Extraction with NLP

## Overview
This exercise extracts patient insights from medical text using an NLP pipeline. It covers text preprocessing, named-entity recognition, sentiment analysis, and visualization to summarize patient narratives.

## What the notebooks cover
- Build a medical text analysis workflow (cleaning, tokenization, stopword removal).
- Apply NLP tools such as `nltk`, `spacy`, and transformer-based sentiment analysis.
- Extract entities and visualize results (e.g., word clouds).
- A consolidated “single code” notebook version is also provided.

## Contents
- `Ex_5_NLP_based_sentient_Analysis_model_for_Patient_Insights.ipynb` — Full NLP workflow with explanations.
- `Ex_5_Singlecode.ipynb` — Condensed, fully executable version of the workflow.
- `Ex_5_NLP_based_sentient_Analysis_model_for_Patient_Insights).docx` — Written explanation of the exercise.
- `Ex_5_NLP_based_sentient_Analysis_model_for_Patient_Insights).pdf` — PDF version of the explanation.

## How to run
Open the notebooks in Jupyter Notebook or Google Colab. Typical dependencies include `pandas`, `numpy`, `nltk`, `spacy`, `transformers`, and `wordcloud`.
