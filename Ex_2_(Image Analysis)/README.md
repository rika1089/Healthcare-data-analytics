# Exercise 2 - Image Analysis

## Overview
This exercise focuses on basic biomedical image analysis workflows. One notebook creates synthetic images and demonstrates preprocessing and segmentation, while the other walks through a general-purpose biomedical image processing pipeline using sample images.

## What the notebooks cover
- Synthetic image generation, blur preprocessing, Canny edge segmentation, and region-property feature extraction.
- Loading biomedical images (via `skimage`), preprocessing (resize/denoise/contrast), segmentation, feature extraction, and detection.

## Contents
- `Ex_2(Synthetic image generation).ipynb` — Synthetic image creation and feature extraction pipeline.
- `Ex_2_DAHC(Image Processing).ipynb` — Biomedical image processing workflow using sample images.

## How to run
Open the notebooks in Jupyter Notebook or Google Colab. Typical dependencies include `numpy`, `matplotlib`, and `scikit-image`.
