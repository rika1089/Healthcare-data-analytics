# Exercise 10 - Social Media Pandemic Data Acquisition & Outbreak Prediction

## Overview
This exercise explores how social media data can be used for early outbreak detection. One notebook simulates pandemic-related posts and trains a classifier, while another outlines a broader pipeline using real social media sources and multiple models.

## What the notebooks cover
- Simulate pandemic-related posts, preprocess text, and build features with `CountVectorizer`.
- Train a Random Forest classifier to flag outbreak-indicating posts.
- Acquire pandemic-related posts (Twitter/Reddit), clean text, create labels, and build features with TF-IDF.
- Train models such as Logistic Regression and LSTM for outbreak prediction.

## Contents
- `Ex_10_(Outbreak_Prediction).ipynb` — Simulated dataset workflow with Random Forest classification.
- `Ex_10_(Social_Media_Pandemic_Data_Acquisition_&_Outbreak_Prediction).ipynb` — Social media acquisition workflow with TF-IDF, Logistic Regression, and LSTM.
- `Ex Num 10- Modified code and explanation with output.docx` — Written explanation and outputs.

## How to run
Open the notebooks in Jupyter Notebook or Google Colab. Dependencies include `pandas`, `scikit-learn`, `nltk`, and (for LSTM) a deep learning framework such as `tensorflow`.
