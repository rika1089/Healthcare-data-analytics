# Exercise 3 - Data Mining on Structured and Unstructured Clinical Data

## Overview
This exercise is documented in a PDF that explains data mining concepts in clinical data, distinguishing structured vs. unstructured data and outlining common mining techniques. It provides conceptual guidance and sample code snippets for clinical data mining workflows.

## Key topics covered
- Clinical data mining goals: predictive modeling, pattern discovery, risk stratification, and improved diagnosis.
- Techniques: classification, clustering, association rule learning, and regression analysis.
- Structured data characteristics (tables, standardized fields) and unstructured data characteristics (free-text notes, images, audio).
- Sample Python tooling references (`pandas`, `numpy`, `matplotlib`, `seaborn`, `re`, `nltk`).
