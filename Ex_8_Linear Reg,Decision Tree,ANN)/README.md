# Exercise 8 - Linear Regression, Decision Tree, and ANN Models

## Overview
This exercise builds and compares multiple prediction models for healthcare data, including linear regression, decision tree regression, and an artificial neural network (ANN).

## What the notebook covers
- Load the diabetes dataset and perform basic preprocessing.
- Train a linear regression model and a decision tree regressor.
- Build and train an ANN using TensorFlow.
- Compare model results and visualize ANN training history.

## Contents
- `Ex_8_Linear Reg,Decision Tree,ANN).ipynb` — Full workflow for three model types.

## How to run
Open the notebook in Jupyter Notebook or Google Colab. Dependencies include `pandas`, `numpy`, `matplotlib`, `scikit-learn`, and `tensorflow`.
