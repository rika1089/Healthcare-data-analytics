# Exercise 4 - Data Mining on Non-Clinical Data for Chronic Disease Management

## Overview
This exercise applies data mining techniques to non-clinical features (demographics, lifestyle, and behavioral factors) to understand chronic disease risk. The workflow includes data exploration, feature scaling, dimensionality reduction, and clustering to identify risk groups.

## What the notebook covers
- Define non-clinical features such as age, BMI, smoking, physical activity, and alcohol consumption.
- Visualize distributions and relationships between features.
- Standardize features for distance-based modeling.
- Use PCA for 2D visualization of the feature space.
- Apply KMeans clustering to identify higher- and lower-risk groups and interpret cluster alignment.

Open the notebook in Jupyter Notebook or Google Colab. Required libraries include `pandas`, `numpy`, `matplotlib`, `seaborn`, and `scikit-learn`.
