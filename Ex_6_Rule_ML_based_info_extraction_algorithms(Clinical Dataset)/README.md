# Exercise 6 - Rule-, Pattern-, and ML-Based Information Extraction

## Overview
This exercise demonstrates three approaches for extracting structured fields (Patient ID, Age, Diagnosis) from clinical text: rule-based regex, pattern-based keyword matching, and a machine learning approach using Naive Bayes.

## What the notebook covers
- Prepare sample clinical notes and define extraction targets.
- Rule-based extraction with regular expressions.
- Pattern-based extraction using keyword searches for each field.
- Machine learning extraction with `CountVectorizer` + `MultinomialNB`.
- Compare accuracy and flexibility across the three approaches.
