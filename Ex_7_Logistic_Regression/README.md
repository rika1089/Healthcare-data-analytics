# Exercise 7 - Logistic Regression

## Overview
This exercise trains a logistic regression classifier on the Pima Indians Diabetes dataset and evaluates performance using common classification metrics.

## What the notebook covers
- Load the diabetes dataset from a public URL.
- Train/test split and model training with `LogisticRegression`.
- Evaluation with accuracy, confusion matrix, classification report, and ROC/AUC.

## Contents
- `dahc7 (1).ipynb` — Logistic regression workflow and evaluation steps.

## How to run
Open the notebook in Jupyter Notebook or Google Colab. Required libraries include `pandas`, `numpy`, `matplotlib`, and `scikit-learn`.
